## 5. Quick Reference: Jakob Nielsen’s 10 Usability Heuristics (`H1`–`H10`)

Use these standardized codes in the usability problems table *(full explanations are included inside the `Word` template)*:

| Code & Heuristic | What to Look For During Booking Evaluation |
| :--- | :--- |
| **H1: Visibility of System Status** | Clear system feedback (loading indicators, confirmed dates/room selection, and immediate total price updates). |
| **H2: Match Between System and the Real World** | Familiar, plain terminology (room types, bed configurations, taxes) without confusing hotel jargon. |
| **H3: User Control and Freedom** | Easy modification of dates, room choices, or add-ons, and effortless backward navigation without losing entered data. |
| **H4: Consistency and Standards** | Consistent buttons, labels, layouts, and pricing across pages aligned with standard booking conventions. |
| **H5: Error Prevention** | Preventing user mistakes before they happen (e.g., disabling unavailable dates, clear non-refundable rate warnings). |
| **H6: Recognition Rather Than Recall** | Keeping selected booking details (dates, guests, room type, cancellation rules) visible throughout checkout. |
| **H7: Flexibility and Efficiency of Use** | Effective search filters (private bathroom, free cancellation, breakfast, price sorting) to speed up comparison. |
| **H8: Aesthetic and Minimalist Design** | Clean, scannable layout free from distracting pop-ups, clutter, and repetitive promotional blocks. |
| **H9: Help Users Recognize, Diagnose, and Recover from Errors** | Plain-language error messages explaining what went wrong and how to fix it immediately. |
| **H10: Help and Documentation** | Easy access to cancellation policies, check-in/out times, luggage storage details, and contact information. |
